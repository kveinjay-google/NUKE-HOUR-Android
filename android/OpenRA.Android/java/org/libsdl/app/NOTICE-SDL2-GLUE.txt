SDL2 Java glue — origin and license

The files in java/org/libsdl/app/ (SDLActivity.java, SDLSurface.java, SDL.java,
SDLAudioManager.java, SDLControllerManager.java, HIDDevice*.java) are based on
the Java glue of SDL version release-2.30.10 from the
official SDL source distribution (https://github.com/libsdl-org/SDL,
tag release-2.30.10, android-project/app/src/main/java/org/libsdl/app/).

This distribution includes local host, surface and input adaptations and is not an unmodified upstream SDL source distribution.

SDL is distributed under the zlib license; the full SDL license text is
reproduced below. AndroidHostBridge.java is an additive, locally authored
bridge file (also zlib-licensed) for the .NET-owned host model and is not part
of upstream SDL.
